Циклы

for
for <переменная> in <итерируемый объект*>:
    < код >
Точное количество выполнений (длина ит. объекта, диапазон в range и т.д.) *итерируемый объект - что-то, что можно перебрать: строка, список, range...
while
while (условие):
    < код >
Выполнение "пока верно условие", а не точное количество раз
Примеры
for i in range(3):
    print(i)
for ch in "abc":
    print(ch)
n = 3
while n > 0:
    print(n)
    n -= 1
break
continue
Оператор прерывания цикла
После срабатывания break цикл завершается вне зависимости от истинности условия, времени работы и проч.
Оператор пропуска итерации
После срабатывания continue данная итерация (прогон) завершается и код переходит к следующей
Примеры
for i in range(10):
    if i == 3:
        break
    print(i)
for i in range(5):
    if i == 2:
        continue
    print(i)
range
Итерируемый объект, создающий набор значений, который зависит от переданных аргументов и их количества
range(b) - создает набор из чисел от 0 до b
range(a, b) - создает набор из чисел от a до b
range(a, b, s) - создает набор из чисел от a до b с шагом s

Списки

Душность
Список - набор или последовательность элементов. Для создания списка используются квадратные скобки [], внутри которых через запятую перечисляются элементы. nums = [1, -3, 42] people = ["C#", "Java", "C++", "Python"] Для создания пустого списка можно использовать пустые скобки или функцию list() empty_list = [] empty_list = list() В одном списке могут быть объекты разных типов данных a = ["Tom", -3.14, 42] Если необходимо создать список, в котором повторяется одно и то же значение (или несколько значений), то можно использовать звездочку * (по сути - это умножение списка на число) numbers = [2] * 6 # 6 раз повторяем 2 print(numbers) # [2, 2, 2, 2, 2, 2] students = ["Bob", "Sam"] * 2 # 2 раза повторяем "Bob", "Sam" print(students) # ["Bob", "Sam", "Bob", "Sam"]
Работа с элементами
Для обращения к конкретному элементу надо использовать индексы - номера элементов. Они начинаются с нуля. То есть первый элемент будет иметь индекс 0, второй - 1, четвертый - 3 и т.д.
