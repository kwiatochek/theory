Синтаксис

Весь код выполняется построчно - сначала первая строка, потом вторая и так далее - и пишется с самого левого края.

Для ограничения блоков кода (if, for и т.д.) используются двоеточия и отступы.

Двоеточие - начало блока. Используется после конструкций if/elif/else, for, while, def и еще кое-где: 

x = 7

if x > 5:
    print(x)

for i in range(4):
    print(i // 2)

while x > 0:
    x -= 1

Отступы определяют, какие команды относятся к блоку. Обычно отступ - это либо Tab, либо 4 пробела: 

x = 3

if x > 0:
    print("Положительное")
    print("Ещё одна команда")

print("Уже вне if")

x = 3

if x > 0:
print("x")    # ошибка, так как нет отступа после двоеточия
print()

print() нужен, чтобы вывести значение: 

x = 5

print("Привет")
print(901)
print(x)

Вывести несколько значений: 

name = "Вася"
age = 16
print(name, age)   # 'Вася' 16

У print есть 2 значения по умолчанию: sep и end

sep отвечает за разделитель между значениями

print("2026", "06", "08", sep="-")  # 2026-06-08

end отвечает за то, что будет выведено после print

print("Привет,", end=" ")
print("мир")  # Привет, мир
input()

input() нужен, чтобы получить данные от пользователя 

name = input()
print(name)

Также можно с подсказкой: 

name = input("Введите имя: ")

Главный нюанс: input() всегда возвращает str

Типы данных

Тип данных - не вид переменной, а то, что может храниться в этой коробочке с названием.

Основные типы данных:

  • int. Обычное целое число
  • float. Число с дробной частью. Разделитель - точка. Дробная часть может быть равной нулю
  • str. Строка, последовательность символов, заключенная в кавычки
  • bool. Всего два значения - True (истина) и False (ложь). Является результатом логических выражений

Чтобы быстро узнать тип переменной, можно воспользоваться встроенной функцией type(): 

a = 10
print(type(a))    # <class 'int'>
b = 10.0
print(type(b))    # <class 'float'>
c = "10"
print(type(c))    # <class 'str'>
d = True
print(type(d))    # <class 'bool'>
Преобразование типов

Значение одного типа можно преобразовать в другой с помощью специальных функций. Например, чтобы преобразовать str в int (если данная строка может быть числом): 

age = "18"        # age будет иметь тип str
age = int(age)    # преобразуем в число
print(age + 1)    # 19, ошибки не будет

Пользовательский ввод через input() по умолчанию имеет тип str, поэтому для работы с числами надо приводить типы:
input() -> str -> преобразование -> нужный тип 

a = input()
b = input()

print(a + b) # если ввести 2 и 3, то получим '23'
a = int(input())
b = int(input())

print(a + b) # если ввести 2 и 3, то получим 5

Условные операторы

Условные конструкции позволяют писать код с ветвлениями, то есть в зависимости от условия выполнять тот или иной код. Проверка всегда начинается с if - если, после которого идет само логическое выражение (проверка равенства, неравенства, результата булевой функции). При истинности условия будет выполнен тот код, который находится в области видимости if'а - блоке if: 

if (условие):
    < код >

Чтобы определить поведение в альтернативном случае, можно использовать оператор else, который выполнится, если выражение в if равно False (ложно). Так как в else попадают все случаи, когда if был равен False, условие в else не указывается. 

if (условие):
    < код >
else:
    < код >

Чтобы определить несколько альтернативных условий, можно использовать блок elif: 

if (условие):
    < код >
elif (условие):
    < код >
  1. Сначала python проверит условие в if. Если оно равно True, то выполнится код из блока if.
  2. Если условие равно False, то python проверит условие из следующего elif.
  3. Если оно True, то выполнится блок elif
  4. Если оно False, то проверяются условия из последующих elif (если они есть)
  5. Если ни одно из условий не было истинным, то выполнится код блока else
x = 5

if x > 0:
    print("Больше нуля")
x = 4

if x % 2 == 0:
    print("Чётное")
else:
    print("Нечётное")
x = -2

if x > 0:
    print("Плюс")
elif x < 0:
    print("Минус")
x = 0

if x > 0:
    print("Плюс")
elif x < 0:
    print("Минус")
else:
    print("Ноль")

Циклы

Циклы используются для повторения одного и того же блока кода некоторое количество раз.

for

Используется для перебора элементов итерируемого объекта 

for <переменная> in <итерируемый объект>:
    < код >
while

Используется, когда необходимо выполнение "пока верно условие" 

while (условие):
    < код >

Пока условие True, цикл продолжает свое выполнение. Главное - следить за изменением переменных, иначе можно получить бесконечный цикл

Примеры
for i in range(3):
    print(i)
for ch in "abc":
    print(ch)
n = 3
while n > 0:
    print(n)
    n -= 1
break
continue

Оператор прерывания цикла

После срабатывания break цикл завершается вне зависимости от истинности условия, времени работы и проч.

Оператор пропуска итерации

После срабатывания continue данная итерация (прогон) завершается и код переходит к следующей

Примеры
for i in range(10):
    if i == 3:
        break
    print(i)
for i in range(5):
    if i == 2:
        continue
    print(i)
range

Итерируемый объект, создающий набор значений, который зависит от переданных аргументов и их количества

  • range(b) - создает набор из чисел от 0 до b - 1
  • range(a, b) - создает набор из чисел от a до b - 1
  • range(a, b, s) - создает набор из чисел от a до b (не включительно) с шагом s

Списки

Душность

Список - набор или последовательность элементов. Для создания списка используются квадратные скобки [], внутри которых через запятую перечисляются элементы: 

nums = [1, -3, 42]
people = ["C#", "Java", "C++", "Python"]
print(nums)
print(people)

Для создания пустого списка можно использовать пустые скобки или функцию list(): 

empty_list = []
print(empty_list)
empty_list = list()
print(empty_list)

В одном списке могут быть объекты разных типов данных

a = ["Tom", -3.14, 42]
print(a)

Если необходимо создать список, в котором повторяется одно и то же значение (или несколько значений), то можно использовать звездочку * (по сути - это умножение списка на число): 

numbers = [2] * 6                # 6 раз повторяем 2
print(numbers)                   # [2, 2, 2, 2, 2, 2]

students = ["Bob", "Sam"] * 2    # 2 раза повторяем "Bob", "Sam"
print(students)                  # ["Bob", "Sam", "Bob", "Sam"]
Сложение списков

Списки можно объединять оператором +. Результатом будет новый список, а исходные списки не изменятся: 

a = [1, 2]
b = [3, 4]
c = a + b
print(c)    # [1, 2, 3, 4]
print(a)    # [1, 2]

Складывать можно только списки. Чтобы добавить один элемент, его нужно обернуть в список: 

nums = [1, 2]
print(nums + [3])    # [1, 2, 3]
print(nums + 3)      # ошибка TypeError

Отличие от append: + создает новый список, а append изменяет существующий: 

nums = [1, 2]
other = nums + [3]
print(nums)     # [1, 2]
print(other)    # [1, 2, 3]
nums.append(3)
print(nums)     # [1, 2, 3]
Работа с элементами

Для обращения к конкретному элементу надо использовать индексы - номера элементов. Они начинаются с нуля. То есть первый элемент будет иметь индекс 0, второй - 1, четвертый - 3 и т.д. 

nums = [0, -17, 8]

В данном примере 0 будет иметь индекс 0, -17 - индекс 1 и 8 - индекс 2. Чтобы обратиться по индексу, необходимо указать название переменной и индекс в квадратных скобках: 

nums = [0, -17, 8]

print(nums[0])    # 0
print(nums[1])    # -17

Для обращения к элементам с конца можно использовать отрицательные индексы, которые будут начинаться с -1 (последний - -1, предпоследний - -2 и т.д.) 

nums = [0, -17, 8]

print(nums[-1])    # 8
print(nums[-2])    # -17

Кроме получения элемента (например, чтобы вывести через print()) по индексу можно менять элементы: 

nums = [0, -17, 8]

nums[1] = -8
print(nums)    # [0, -8, 8]
Перебор элементов

Чтобы посмотреть элементы по порядку или провести с ними какую-либо другую манипуляцию, их необходимо перебрать по одному. Для этого можно использовать циклы - как for, так и while.

Основная идея - перебирать индексы элементов, и уже по ним доставать элементы. Главное - знать количество элементов в списке. Для этого используется функция len(переменная) - возвращает длину списка. Длина = количество элементов. Последний индекс = len(nums) - 1 

nums = [1, 3, 5]
print(len(nums))    # 3

Вернемся к перебору:

nums = [0, -17, 8]
for i in range(len(nums)):
    print(nums[i])

В переменную i, которая существует только внутри цикла, по очереди записываются значения от 0 до длины списка - 1

Или через while:

nums = [0, -17, 8]
i = 0
while i < len(nums):
    print(nums[i])
    i += 1    # i = i + 1

Также есть еще один способ перебора элементов через цикл for:

nums = [0, -17, 8]

for num in nums:
    print(num)

Такой вариант дает сам элемент в переменной num, а не его индекс. Поэтому для замены элемента чаще используют индексы

Срезы

Иногда возникает необходимость получить только часть списка. Для этого существует специальный синтаксис - срезы:

nums[start:end:step]:

  • start: начало, включается
  • end: конец, не включается
  • step: шаг, через который будут браться элементы. По умолчанию равен 1

Немного сокращений:

  • nums[start:]: от start до конца
  • nums[:end]: от начала до end
  • nums[::]: весь список
  • nums[::-1]: весь список в обратном порядке
nums = [0, 1, 8, -17, 1, -3, 4, 161]

print(nums[:4])       # [0, 1, 8, -17]
print(nums[1:5])      # [1, 8, -17, 1]
print(nums[1:6:2])    # [1, -17, -3]

Можно использовать и отрицательные индексы:

nums = [0, 1, 8, -17, 1, -3, 4, 161]

print(nums[:-2])     # [0, 1, 8, -17, 1, -3]
print(nums[-5:])     # [-17, 1, -3, 4, 161]
print(nums[2:-3])    # [8, -17, 1]
print(nums[::])      # [0, 1, 8, -17, 1, -3, 4, 161]
print(nums[::-1])    # [161, 4, -3, 1, -17, 8, 1, 0]
Методы списков

Списки имеют целый ряд методов для взаимодействия с ними:

  • append(x): добавляет x в конец списка
  • insert(i, x): добавляет x по индексу i, все после него - сдвигает на одну позицию
  • clear(): очищает весь список
  • count(x): возвращает количество вхождений x в список
  • sort(): сортирует элементы по возрастанию*
  • remove(x): удаляет первое вхождение x в список
  • index(x): возвращает индекс первого вхождения x в список

Для вызова одного из этих методов надо поставить точку после имени переменной и указать название метода с его аргументами

nums = [5, 2, 8, 2]

nums.append(7)
print(nums)             # [5, 2, 8, 2, 7]

nums.insert(1, 10)
print(nums)             # [5, 10, 2, 8, 2, 7]

nums.remove(2)
print(nums)             # [5, 10, 8, 2, 7]

print(nums.index(8))    # 2
print(nums.count(2))    # 1

nums.sort()
print(nums)             # [2, 5, 7, 8, 10]

nums.clear()
print(nums)             # []

Помимо них, в язык зашиты встроенные функции для работы со списками:

  • max(), min(): возвращает наибольший/наименьший элемент списка
  • sorted(list): возвращает отсортированный список
  • len(): возвращает длину списка
nums = [5, 2, 8, 2]

print(max(nums))       # 8
print(min(nums))       # 2
print(sorted(nums))    # [2, 2, 5, 8]
print(len(nums))       # 4

P.S.

nums = [5, 2, 8, 2]

print(sorted(nums))    # создает новый список: [2, 2, 5, 8]
print(nums)            # исходный не изменился: [5, 2, 8, 2]

nums.sort()            # меняет список
print(nums)            # [2, 2, 5, 8]

Если элемента в списке нет, remove и index вызовут ошибку (ValueError). Чтобы этого избежать, можно заранее проверить наличие элемента оператором in. Он возвращает True или False: 

nums = [5, 2, 8, 2]

print(8 in nums)            # True
print(7 in nums)            # False

if 7 in nums:
    nums.remove(7)

if 8 in nums:
    print(nums.index(8))    # 2

Обратная проверка записывается как not in: элемента в списке нет 

nums = [5, 2, 8, 2]

print(7 not in nums)   # True

* для сортировки по убыванию после названия переменной через запятую необходимо указать флаг reverse=True

Списки списков

Списки могут состоять из других списков: 

students = [
    ["Вася", 19],
    ["Кира", 20],
    ["Маша", 19],
    ["Петя", 21]
]

print(students[0])        # ['Вася', 19]
print(students[0][0])     # 'Вася'
print(students[-1][1])    # 21

a[i][j] - j-ый элемент вложенного списка i

Все взаимодействие с элементами аналогично работе с обычными, одномерными списками. Также не запрещено иметь внутри списка списки разной длины: 

all_in_one = [
    [0],
    ["Вася", "друг Васи"],
    []
]

print(all_in_one)

P.S. Записывать список можно и в строчку, как одномерный, но данный способ делает содержимое более наглядным

Генераторы списков

Используются для компактного создания списков.

Фактически заменяют создание списков через циклы. Например, список из квадратов чисел от 1 до 9 можно создать так: 

squares = []
for i in range(1, 10):
    squares.append(i ** 2)

print(squares)

А можно так: 

squares = [i ** 2 for i in range(1, 10)]
print(squares)   # [1, 4, 9, 16, 25, 36, 49, 64, 81]

Генераторы более читабельны, чем те же циклы, к тому же пишутся в одну строку

Основной синтаксис: 

[выражение for переменная in итерируемый объект]
  • выражение - что делаем
  • переменная - с чем делаем
  • ит. объект - откуда берем

Генераторы не изменят ит. объект, а лишь создадут новый

Помимо обязательного for внутрь генератора можно добавлять и if - тогда получится список, элементы которого удовлетворяют определенному условию. Синтаксис: 

[выражение for переменная in итерируемый объект if условие]

По сути, это - фильтр. Он не заменяет значения (elif и else не работают), а именно берет те, которые подходят. 

print([i for i in range(1, 10) if i % 2 == 0])   # [2, 4, 6, 8]

Чтобы сделать именно комбинацию for + if/else, надо писать так (можно и в одну строчку): 

[выражение_если_true 
if условие else выражение_если_false 
for переменная in итерируемый объект]

Например, генератор, создающий список из квадратов четных и кубов нечетных чисел от 1 до 8 выглядит так: 

print([i ** 2 if i % 2 == 0 else i ** 3 for i in range(1, 9)])   # [1, 4, 27, 16, 125, 36, 343, 64]

Для полного взрыва мозга в генераторах можно использовать вложенные циклы. 

list1 = [1, 2, 3]
list2 = ['a', 'b']
pairs = [(x, y) for x in list1 for y in list2]
print(pairs)    # [(1, 'a'), (1, 'b'), (2, 'a'), (2, 'b'), (3, 'a'), (3, 'b')]

Порядок важен! Сначала выполняется внешний цикл, затем внутренний

Строки

Основы

Строка (str) - последовательность символов, заключенная в кавычки. Кавычки могут быть как одинарными, так и двойными - главное, чтобы закрывающая была такой же, как открывающая: 

s = "Привет"
t = 'мир'
print(s)    # Привет
print(t)    # мир

Длина строки (количество символов, включая пробелы и знаки препинания) определяется функцией len(): 

print(len("Привет"))   # 6
print(len("a b"))      # 3

Для объединения строк используется оператор +, для повторения - *:

s = "Привет"
t = "мир"
print(s + ", " + t)   # Привет, мир
print(t * 3)          # миримирмир

Оператор + работает только со строками. Чтобы присоединить число, его нужно сначала преобразовать функцией str(): 

age = 16
print("Возраст: " + str(age))   # Возраст: 16
print("Возраст: " + age)        # ошибка TypeError
Индексы и срезы

Обращение к символам по индексу (с нуля, отрицательные индексы - с конца) и срезы работают так же, как в списках (см. раздел «Списки»). Результатом среза будет новая строка: 

s = "программа"
print(s[0])      # п
print(s[-1])     # а
print(s[2:5])    # огр
print(s[::-1])   # аммаргорп

Обращение по несуществующему индексу вызывает ошибку, а срез, выходящий за границы строки, просто обрежется: 

print(s[5:100])   # амма
print(s[100])     # ошибка IndexError
Перебор

Строка - итерируемый объект, поэтому ее можно перебирать циклом for - либо по индексам, либо сразу по символам: 

s = "abc"
for i in range(len(s)):
    print(s[i])

for ch in s:
    print(ch)

Например, подсчет символов определенного вида:

s = "banana"
cnt = 0
for ch in s:
    if ch == "a":
        cnt += 1
print(cnt)   # 3
Поиск и подсчет
  • count(x): возвращает количество вхождений подстроки x в строку
  • find(x): возвращает индекс первого вхождения x, а если его нет - -1
  • rfind(x): возвращает индекс последнего вхождения x, а если его нет - -1
  • index(x): работает как find, но если подстроки нет - вызывает ошибку (ValueError)
  • x in s: проверяет, есть ли подстрока x в строке (True / False)
s = "abracadabra"
print(s.count("a"))      # 5
print(s.find("bra"))     # 1
print(s.rfind("bra"))    # 8
print(s.find("z"))       # -1
print("cad" in s)        # True

Отличие find от index - в поведении, когда подстроки нет:

print("abc".find("z"))     # -1
print("abc".index("z"))    # ошибка ValueError

count считает только непересекающиеся вхождения. Чтобы посчитать все, в том числе пересекающиеся, нужно перебирать срезы: 

s = "aaaa"
print(s.count("aa"))     # 2

cnt = 0
for i in range(len(s) - 1):
    if s[i:i + 2] == "aa":
        cnt += 1
print(cnt)               # 3
Замена и очистка
  • replace(a, b): заменяет все вхождения подстроки a на b. Необязательный третий аргумент - максимальное количество замен
  • strip(): удаляет пробелы и переносы строк в начале и в конце строки. lstrip() удаляет только слева, rstrip() - только справа
  • strip(chars): удаляет в начале и в конце любые символы из chars
t = "abababab"
print(t.replace("ab", "X"))       # XXXX
print(t.replace("ab", "X", 2))    # XXabab

Замена идет слева направо, заменяемые вхождения не пересекаются:

print("aaa".replace("aa", "b"))   # ba
s = "  hello world  "
print("[" + s.strip() + "]")     # [hello world]
print("[" + s.lstrip() + "]")    # [hello world  ]
print("[" + s.rstrip() + "]")    # [  hello world]
print("xxabcxx".strip("x"))      # abc
split и join
  • split(sep): разбивает строку на список подстрок по разделителю sep. Без аргумента разделителем считаются любые пробельные символы
  • sep.join(список): объединяет строки из списка в одну, вставляя sep между ними
words = "красный жёлтый зелёный".split()
print(words)                    # ['красный', 'жёлтый', 'зелёный']
print("2026-06-08".split("-"))  # ['2026', '06', '08']
print("-".join(words))          # красный-жёлтый-зелёный
sorted

Функция sorted() для строки возвращает список символов (а не строку), упорядоченных по кодам. Чтобы получить строку, список нужно объединить через join: 

s = "banana"
print(sorted(s))                          # ['a', 'a', 'a', 'b', 'n', 'n']
print("".join(sorted(s)))                 # aaabnn
print("".join(sorted(s, reverse=True)))   # nnbaaa

Коды заглавных букв меньше кодов строчных, поэтому они идут раньше:

print(sorted("aBcA"))   # ['A', 'B', 'a', 'c']
Регистр, проверки, коды символов
  • upper(), lower(): переводят строку в верхний / нижний регистр
  • isdigit(): проверяет, что все символы - цифры. isalpha(): проверяет, что все символы - буквы
  • startswith(x), endswith(x): проверяют, начинается / заканчивается ли строка на x
  • ord(c): возвращает код символа. chr(n): возвращает символ по коду
print("Hello".upper())         # HELLO
print("123".isdigit())         # True
print("abc".startswith("ab"))  # True
print(ord("A"))                # 65
print(chr(66))                 # B
print(chr(ord("a") + 1))       # b

P.S. Строки сравниваются посимвольно, по кодам символов:

print("Z" < "a")     # True
print("10" < "9")    # True
f-строки

f-строки позволяют вставлять значения переменных и выражений прямо в строку. Перед открывающей кавычкой ставится буква f, а подставляемые значения записываются в фигурных скобках: 

name = "Вася"
age = 16
print(f"Меня зовут {name}, мне {age} лет")   # Меня зовут Вася, мне 16 лет

Внутри скобок может быть любое выражение: арифметика, вызов функции или метода, обращение по индексу: 

a = 2
b = 3
print(f"{a} + {b} = {a + b}")           # 2 + 3 = 5

name = "вася"
print(f"{name.upper()} {len(name)}")    # ВАСЯ 4
print(f"{name[0]}{name[-1]}")           # вя

Кавычки внутри скобок должны отличаться от тех, которыми обрамлена сама f-строка: 

print(f"{'abc'.upper()}")   # ABC

Для вывода переменных вместе с текстом есть три способа. Результат у них одинаковый, но + требует ручного преобразования типа, а запятая в print всегда добавляет пробел: 

age = 16
print("Возраст: " + str(age))   # Возраст: 16
print("Возраст:", age)          # Возраст: 16
print(f"Возраст: {age}")        # Возраст: 16
print("Возраст: " + age)        # ошибка TypeError

После двоеточия внутри скобок задается формат. Например, :.2f - вещественное число с двумя знаками после запятой (округление выполняется автоматически): 

x = 3.14159
print(f"{x:.2f}")   # 3.14
print(f"{x:.1f}")   # 3.1
print(f"{x:.0f}")   # 3

Число задает ширину поля, а символы <, > и ^ - выравнивание по левому краю, правому и по центру. Для строк по умолчанию выравнивание левое, для чисел - правое: 

print(f"[{'ab':<5}]")    # [ab   ]
print(f"[{'ab':>5}]")   # [   ab]
print(f"[{'ab':^6}]")   # [  ab  ]
print(f"[{7:5}]")       # [    7]

Ноль перед шириной дополняет число нулями слева:

print(f"{7:03}")          # 007
print(f"{5:02}:{9:02}")   # 05:09

Чтобы вывести саму фигурную скобку, ее нужно удвоить:

print(f"{{x}} = {5}")   # {x} = 5
Строки неизменяемы

В отличие от списка, элемент строки нельзя изменить по индексу:

nums = [1, 2, 3]
nums[0] = 9
print(nums)      # [9, 2, 3]
s = "abc"
s[0] = "X"       # ошибка TypeError

Методы строк не изменяют исходную строку, а возвращают новую, поэтому результат нужно сохранять в переменную: 

s = "abc"
s.replace("a", "X")
print(s)         # abc
s = s.replace("a", "X")
print(s)         # Xbc

Заменить символ по индексу можно, собрав новую строку из срезов:

s = "abc"
s = s[:1] + "X" + s[2:]
print(s)         # aXc

Оператор in для строки проверяет наличие подстроки, а для списка - наличие элемента:

print("a" in "cabd")         # True
print("ab" in "cabd")        # True
print("a" in ["ab", "cd"])   # False
